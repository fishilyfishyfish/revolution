# 진화 시뮬레이터

브라우저에서 도는 진화 시뮬레이터. "진화처럼 보이는 연출"이 아니라, 에너지가 0이 되면 죽고 조건을 채우면 번식한다는 규칙만으로 선택과 종분화가 일어나는지 본다. 사용자는 환경만 바꿀 수 있고 개체에는 손댈 수 없다.

TypeScript + Vite + Canvas 2D. 시뮬레이션은 Web Worker에서 돌고 렌더링과 분리돼 있다. 정적 빌드라서 GitHub Pages에 올라간다.

```bash
npm i
npm run dev        # 개발 서버
npm test           # 에너지 불변식, 재현성, 원칙 점검 테스트
npm run build      # dist/ (정적 파일)
npx tsx scripts/headless.ts --stage 7 --seed 1 --ticks 100000   # 헤드리스 실행
npx tsx scripts/barrier.ts --seed 1 --isolate 60000 --after 20000  # 장벽 종분화 실험
```

`main`에 푸시하면 `.github/workflows/pages.yml`이 테스트, 빌드, Pages 배포를 한다. 저장소 설정에서 Pages 소스를 "GitHub Actions"로 바꿔야 한다.

## 원칙을 코드에서 지키는 방식

| 원칙 | 구현 |
|---|---|
| 인위 선택 금지 | 적합도·점수·상위 N% 루프가 없다. `World.kill`은 에너지 0(아사/질병), 피식, 운석에서만 불린다. 번식은 `ready()`(성숙+번식 임계 에너지)와 뇌의 번식 출력이 모두 켜졌을 때만 일어난다. |
| 행동 하드코딩 금지 | 이동·회전·먹기/공격·번식·짝짓기 신호는 전부 29-8-8 신경망 출력이다. 코드에 "먹이 쪽으로 가라" 같은 규칙은 없다. `features.brain=false`일 때만 출력이 순수 난수가 되는 귀무 모형(단계 2~3 검증용). |
| 형질에 몰래 기울이기 금지 | 모든 형질은 `genome.ts`의 `Traits.decode`에서 이득과 비용이 같이 나온다. `tests/rules.test.ts`가 비용·이득 방향을 검사한다. |
| 사용자는 환경만 | 개입 종류는 `INTERVENTION_KINDS`(지형/바이옴/음식/전역/운석/역병/기후) 7가지뿐이다. 개체 편집·이동·복제·제거·소환 API가 없고 테스트가 이를 확인한다. |

## 에너지 회계

시스템 에너지 = 식물 + 개체(저장 + 구조) + 사체 + 토양. 외부 유입은 햇빛으로 식물이 자라는 것뿐이고, 유출은 대사 열손실뿐이다.

- 식물이 자랄 때 성장량 g 중 `soilShare` 몫은 토양에서 이전되고 나머지가 햇빛 유입이다. 그래서 토양 비옥도는 "식물이 자라면 소모"된다.
- 먹을 때 소화되지 않은 몫(1 − 효율)은 배설물로 그 자리 토양에 간다. 공격으로 입힌 피해 중 먹지 못한 몫은 사체로 간다.
- 개체가 죽으면 `구조 에너지 + 남은 저장`이 전부 그 자리 사체가 된다. 사체는 매 틱 일정 비율이 같은 셀 토양으로 분해된다.
- 번식에서는 부모 저장이 자식의 구조 + 저장으로 이전될 뿐이다.
- 운석은 개체를 사체로, 범위 안 식물을 사체로 바꾼다(소멸 없음). 지형을 물/산으로 칠하면 그 셀 식물이 토양으로 돌아간다. 음식 브러시는 햇빛 배율(`sunMul`)을 바꿔 유입량만 조정한다.
- 전멸 후 재시작도 식물 재고에서 에너지를 이전해서 개체를 만든다.

`tests/energy.test.ts`가 단계 1~6 설정과 전 기능 + 모든 개입 시나리오에서 매 틱 `Δ총량 = 유입 − 유출`을 상대오차 1e-9 이하로 검사한다.

## 구조

```
src/sim/      rng · config · genome(게놈/형질/뇌) · world(틱 루프) · analysis(종 판정/통계) · snapshot · lineage
src/worker/   sim.worker.ts (시뮬레이션 루프, 프레임/통계 전송, 자동 스냅샷)
src/ui/       맵 렌더러, 차트, 계통수, 뇌 시각화, 분기 비교

tests/        energy / determinism / rules
```

## 시뮬레이션 규칙 요약

- 게놈: 형질 30개 + 뇌 가중치 312개 + 뇌 구조 마스크 304개(실수 배열). 형질은 몸 크기, 최대 속도, 시야 거리/각도, 식성 4(식물 3종 + 고기, 합 고정), 적정 기온, 질병 저항, 번식 임계, 자식 에너지 비율, 유성 성향, 돌연변이율(진화함), 색(중립), 진동수, 소화관(섭식 용량), 수생 적응, 수명, 갑옷, 이빨·발톱, 독, 후각, 청각, 기온 허용폭, 단열, 겨울잠, 한배 새끼 수, 짝 까다로움, 면역형. 모든 형질은 이득과 비용이 같이 있다(`tests/rules.test.ts`).
- 성장: 새끼는 성체의 50% 구조로 태어나 100틱에 걸쳐 저장 에너지를 구조 에너지로 바꿔 자란다. 번식은 성체만 한다.
- 식물: 셀별 성장이 자기 셀과 이웃 4칸의 같은 종 바이오매스에 비례한다(씨앗 퍼짐). 물에는 수초(식물 C)만 자란다.
- 사망: 에너지 0(아사/질병), 피식, 운석, 노화, 극한 기온, 서식지 부적합. 몸은 전부 사체로 남는다.
- 질병: 역병 도구 외에 상시 병원체가 있다. 면역형이 병원체 균주와 가까울수록 취약하고, 균주는 인구의 평균 면역형을 따라 움직인다.
- 뇌: 입력 29(감각 21 + 기억 8: 옵션, 꺼져 있으면 0) (식물 방향/거리/종류, 사체 방향/거리, 가장 가까운 개체의 방향/거리/크기/색/게놈 유사도, 내 에너지, 기온, 지형, 노이즈, 진동자) → 은닉 8(tanh) → 출력 8(회전, 가속, 먹기, 번식 시도, 짝짓기 신호, 웅크림, 휴식, 공격 — 먹기로는 개체를 해칠 수 없다). 입력은 가장 가까운 개체의 속도·접근, 앞쪽 지형, 최근 피해, 상대의 발톱, 기온 편차도 포함한다(21개).
- 대사: 기초(몸무게^0.75, 저항·돌연변이 교정 비용 포함), 이동(질량×속도², 지형 배수), 시야(면적 비례), 체온 조절((기온−적정)²), 뇌(상수 + |w| 평균), 행동/번식 시도, 감염 시 추가.
- 무성생식: 에너지를 나눠 자식 생성 + 유전자별 가우시안 돌연변이(σ = 부모의 돌연변이율). 유성생식: 짝 찾기 상태(최대 40틱)에서 서로 신호를 켠 두 개체가 접촉하면 호환성 `1 − d/dmax`로 성공 판정, 교차(뇌는 은닉 뉴런 단위 블록) + 변이, 양쪽이 반씩 부담.
- 종 판정: (a) 게놈 거리 리더 클러스터링(지속 ID, 병합), (b) 호환성 그래프(거리 < dmax)의 연결 성분. 둘 다 읽기 전용 관측이고 시뮬레이션에 영향이 없다.
- 개체마다 ID, 부모 ID(들), 출생/사망 틱, 사망 원인을 `lineage.ts`에 기록한다.

## 시작 생물종 프리셋과 수중 생태계

새 월드를 만들 때 파일 패널에서 시작 집단(🦌 초식, 🐗 잡식, 🐺 육식, 🐟 물고기, 🦈 수중 포식자)과 마릿수, 물 비율을 고른다. 이건 초기 조건일 뿐이고, 시작한 뒤에는 개체를 건드릴 수 없다. 프리셋은 형질 시작값만 다르며 이후 진화는 자유롭다. 시작 에너지는 식물 재고에서 이전된다.

- 수생 적응 유전자(형질 17번째): 물에서는 빠르고 싸게, 육지에서는 느리고 비싸게 움직인다. 반대로 육상형은 물에서 불리하다. 양쪽에서 다 유리한 값은 없다.
- 물 셀에는 수초(식물 C)만 자란다. 산에는 식물이 없다. 물을 칠하면 식물 A·B는 토양으로 돌아가고 수초는 남는다.

## 뇌 구조 변이 (단계 8, 옵션)

새 월드 파일 패널의 "뇌 구조 변이 (NEAT식)" 체크박스(또는 `features.neat`). 연결·은닉 노드의 켜짐/꺼짐 마스크가 게놈에 들어가 연결/노드 추가·제거가 진화로 일어난다. 작은 뇌에서 시작하고 활성 연결·노드가 많을수록 유지비가 늘어난다. 혁신 번호와 종 분할은 구현하지 않은 단순화된 방식이다.

## UI

- 도구: 지형/바이옴/음식 브러시, 운석, 역병, 전역 슬라이더(햇빛·평균 기온·계절 진폭/주기), 빙하기/온난화(서서히 이동). 모든 개입은 틱·종류·영역과 함께 로그에 기록되고 그래프에 점선 마커로 표시된다.
- 개입 직전 상태가 자동 스냅샷으로 저장된다(브러시 연타는 200틱에 한 번). 스냅샷 옆 "분기 비교"를 누르면 같은 상태에서 "개입 안 한 A"와 "개입한 B"가 두 워커에서 나란히 돈다.
- 관찰: 개체 수, 형질 평균 ± σ, 형질 분포, 무성/유성 비율, 에너지 저장량, 대사 비용 구성, 종 수 추이(a/b 동시), 종별 개체 수, 계통수(멸종 가지 제거 옵션), 개체 클릭 시 게놈·뇌 활성화·에너지·계보(읽기 전용).
- 저장/불러오기: 개입 로그와 통계 이력을 포함한 JSON.
- 속도 ×1~×100(×1 = 30틱/초), "최대" 모드, 렌더 끄기.

## 저장 파일 호환
저장 파일은 버전마다 게놈 구조가 달라졌다(형질·뇌 입력/출력이 늘어남). 옛 파일은 불러올 때 현재 구조로 자동 변환한다(`src/sim/migrate.ts`): 같은 자리의 형질·뇌 가중치는 그대로 옮기고, 새 형질은 창시 집단 기본값, 새 뇌 입력은 가중치 0, 새 출력은 꺼짐으로 채운다. 변환한 월드는 현재 규칙(비용 계수 등)으로 이어서 진행된다. 구조를 알 수 없는 파일은 이유와 함께 거부한다. 지원하는 옛 구조는 게놈 길이 189/190/191/243/251/467/468이다.
